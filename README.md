## 기능 요구 사항

입력한 문자열에서 숫자를 추출하여 계산기 구현

### 입력 기능

입력 구분 기능

- [ ] 입력 문자열의 첫 문자가 `//`으로 시작하면 커스텀 구분자, 숫자로 시작하면 기본 구분자 처리
  - 유효성 검증
  - [ ] 입력 문자열의 첫 문자가 `//`과 숫자가 아니라면 예외 처리
  - [ ] 입력 문자열의 마지막 문자가 숫자가 아니라면 예외 처리

기본 구분자 입력 기능

- [ ] 입력값이 없거나 공백인 경우 0으로 처리
- [ ] 구분자 `:`, `,`를 기준으로 문자열 파싱
  - 유효성 검증
  - [ ] 입력 문자열에 `:`, `,`이 아닌 다른 구분자가 존재하면 예외 처리
  - [ ] 구분자 사이에 숫자가 존재하지 않는다면 예외 처리
  - [ ] 양수가 아닌 숫자가 입력되면 예외 처리

커스텀 구분자 입력 기능

- [ ] 숫자가 입력되지 않았다면 0으로 처리
- [ ] `//`와 `\n` 사이의 문자를 기준으로 문자열 파싱
  - 유효성 검증
  - [ ] 커스텀 구분자를 제외하고 다른 구분자가 존재하면 예외 처리
  - [ ] 커스텀 구분자 사이에 숫자가 존재하지 않는다면 예외 처리
  - [ ] 양수가 아닌 숫자가 입력되면 예외 처리
  - [ ] 구분자의 길이가 2이상인 경우 예외 처리
  - [ ] 커스텀 구분자가 입력되지 않았다면 예외 처리

예외 처리

- [ ] 잘못된 입력에 대한 예외 처리는 `IllegalArgumentException`을 발생 후 어플리케이션 종료

### 출력 기능

- [ ] 계산 시작 메시지 출력 기능
  - `덧셈할 문자열을 입력해 주세요.`
- [ ] 계산 결과 메시지 출력 기능
  - `결과 : n`

### Domain

- [ ] 파싱된 숫자를 저장하는 리스트

### Service

- [ ] `calculate()`: 저장된 숫자를 더하는 함수

### Utils

- [ ] `readLine()`: `camp.nextstep.edu.missionutils`에서 제공하는 `Console` API
- [ ] `checkExpression()`: 입력받은 문자열이 올바른지 검증
